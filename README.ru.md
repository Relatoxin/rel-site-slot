# SLOT

[![English](assets/readme/en.svg)](README.md)

Учебный концепт интерфейса сайта для онлайн-записи.

## Что реализовано

- Адаптивная вёрстка и мобильное меню.
- Выбор услуги, даты и времени.
- Демонстрационное подтверждение без создания реальной записи.

## Локальный запуск

Откройте `index.html` для английской версии или `ru.html`.

## Шрифты

Poppins, Roboto, Inconsolata.
